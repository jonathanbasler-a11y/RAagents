# DR-03 Asset Profile and Target Product Profile: OST-4417

| Attribute | Detail |
|---|---|
| Code name | OST-4417 (nonproprietary name: application pending, not yet assigned) |
| Mechanism | Oral, selective inhibitor of the TRX-7 transcriptional cofactor; disrupts a lineage-restricted survival program in TRX-7-high tumors |
| Dose and form | 150 mg tablet, once daily, continuous 28-day cycles |
| Indication (target) | Adults with locally advanced or metastatic intrahepatic cholangiocarcinoma, TRX-7-high by IHC (H-score 150 or higher), after at least one prior systemic therapy |
| Biomarker | TRX-7 IHC assay, Lumenar TRX-7 IHC Assay (clinical trial assay, CTA version 2) |
| Regulatory status | Phase III enrolling; no marketing application filed anywhere |
| Combination product | None for the drug; the CDx is an in vitro diagnostic (see DR-14) |

## Target product profile (TPP) summary

| Element | Minimum | Target |
|---|---|---|
| Efficacy (Phase III) | PFS HR 0.70 or better vs investigator's choice chemotherapy | PFS HR 0.60 and OS trend favorable |
| Efficacy (Phase 2 cohort B, accelerated approval) | Confirmed ORR 35% or higher, median DoR 6 months or longer | ORR 40% or higher |
| Safety | Manageable hepatic events with monitoring | No REMS |
| Label | Biomarker-selected indication; accelerated approval with confirmatory Phase III | Full approval on Phase III PFS and OS |
| Storage | 24-month shelf life, room temperature | 36 months |
