# DR-10 Draft Labeling and Claims (company working draft v0.3, 2026-08)

## Draft indication
"OST-4417 is indicated for the treatment of adult patients with locally advanced or metastatic cholangiocarcinoma whose tumors express TRX-7, as detected by an FDA-approved test, who have received prior systemic therapy."

## Draft claims

| # | Claim | Stated support |
|---|---|---|
| L1 | "Indicated for cholangiocarcinoma" (intrahepatic and extrahepatic) | Study 101 cohort B (intrahepatic only enrolled) |
| L2 | "Improves overall survival" | Study 301; OS data do not exist yet; cohort B OS immature |
| L3 | "Durable responses (median DoR 9.8 months)" | Deck version (DR-02); BICR-confirmed value is 8.4 months (DR-04) |
| L4 | "No Hy's law cases observed" | Safety summary (DR-12) |
| L5 | "First-in-class" | Company statement; not a label element |
| L6 | "Once-daily oral, no routine hepatic monitoring required" | Study 101 monitoring plan required liver tests every 2 weeks for 12 weeks |
| L7 | Accelerated approval statement and confirmatory trial description | Study 301 (OS key secondary) |
